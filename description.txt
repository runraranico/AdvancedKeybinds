Features

## Key Binding Screen

Additional features for Terraria's standard Key Mapping screen.
 - Adds an Undo button to the Key Mapping screen
 - Right-click to clear the current binding
 - Middle-click to restore the default binding
 
## Combo Panel

Click a key binding to open the combo panel.
 - Assign up to 3 keyboard keys or mouse buttons
 - Single-key hold actions (while pressed or on release, adjustable duration)
 - Single-key double-tap action (ver 6.1.0)
 - Custom display names for individual keys
 - Undo / Clear / Save functions inside the combo panel

## Additional Keys
You can now assign “Additional Keys” to 9 keybinds, ranging from Hook and Auto-Select to Inventory.

## Notes
 - Hold actions are available only for single-key bindings.
 - Assigning Left Click by itself requires confirmation (save again to confirm).
 - Some MOD-specific special inputs cannot be captured.
 - Long-press Caps Lock is intended for ANSI keyboards.
 - On Japanese (JIS) keyboards, tapping Caps Lock works normally, but long-press is not supported.
 - Dead keys / accent keys (for example, the German accent key) may display different names depending on the active Windows keyboard layout.
 - Fixed an issue where some keys unsupported by Terraria/tModLoader's default key binding settings could be registered in Advanced Keybinds (AK), but would not function.
 - Some special keys may still have hardware or OS limitations
